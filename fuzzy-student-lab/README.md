# Нечёткие величины Стьюдента — кластерный анализ

Комплексное практическое занятие по дисциплине «Неклассические логики» (МАИ, институт №8).

**Вариант:** нечёткая величина, функция принадлежности которой имеет вид плотности распределения Стьюдента:

```
μ(x) = (1 + ((x − x0) / s)² / ν) ^ (−(ν + 1) / 2)
```

`x0` — центр (μ = 1), `s` — масштаб, `ν` — число степеней свободы (ν = 1 — Коши, ν → ∞ — Гаусс).

α-срез: `[x0 − s·g; x0 + s·g]`, где `g = √(ν·(α^(−2/(ν+1)) − 1))`.

## Запуск

### Вариант 1 — готовая программа (Windows, Python не нужен)

Скачать `FuzzyStudent.exe` (раздел Releases или папка `dist/`) и запустить двойным щелчком.
Журнал работы пишется в `logs\fuzzy_log.txt` рядом с программой.

### Вариант 2 — из исходников (Windows / Linux / macOS, Python 3.10+)

```bash
git clone <ссылка на репозиторий> UnclassicLogic
cd UnclassicLogic/fuzzy-student-lab
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### Сборка .exe самостоятельно

```
build_exe.bat          → dist\FuzzyStudent.exe
```

### Тесты и пример использования библиотеки

```bash
python -m unittest discover tests      # 30 тестов
python examples/use_library.py         # библиотека без GUI
```

## Возможности

| Вкладка | Что делает |
|---|---|
| 1. Множество величин | генерация 100–300 величин (с группами или полностью случайно, с зерном), ручной ввод с предпросмотром, таблица с границами носителя, сохранение/загрузка JSON, вывод в журнал |
| 2. α-срез | все величины на одном графике, ползунок α (горизонтальная линия), выделение величин, прошедших срез; счётчик «подходит N из M»; отбор подмножества и работа с ним; вид «до» и «после» среза |
| 3. Операции | A + B, A − B, A × B, A ÷ B (в т.ч. с чётким числом) по α-срезам; результат как величина Стьюдента и точный результат на одном графике; сравнение: по центрам, Poss(A ≥ B), Nec(A ≥ B), Poss(A = B) |
| 4. Кластеризация | иерархическая кластеризация (Уорд / дальний / средний / ближний сосед); разбиение на заданное число кластеров k **или** по критерию — порогу расстояния h; дендрограмма перекрашивается и показывает линию среза; величины на плоскости (x0, s) по цветам; таблица кластеров |
| 5. Журнал | лог всех действий (также в файле `logs/fuzzy_log.txt`) |

Светлая / тёмная тема: меню **Вид → Тёмная тема** (Ctrl+T); выбор сохраняется в `settings.ini` рядом с программой.

## Структура

```
fuzzy_student/      независимая библиотека (numpy + scipy, без GUI)
  student.py        класс StudentFuzzy: μ(x), α-срезы, границы, генерация случайного значения
  arithmetic.py     + − × ÷ по α-срезам, аппроксимация результата величиной Стьюдента
  compare.py        сравнение, возможность / необходимость
  fuzzy_set.py      множество величин, отбор подмножества по α, файлы JSON
  generator.py      генерация набора величин
  clustering.py     метрика по α-срезам, иерархическая кластеризация
  journal.py        журнал (лог)
gui/                интерфейс на PyQt6 + matplotlib
tests/              модульные тесты (unittest)
examples/           пример подключения библиотеки к внешней программе
main.py             точка входа
build_exe.bat       сборка портативного .exe (PyInstaller)
```

## Использование библиотеки

```python
from fuzzy_student import StudentFuzzy, generate_set, ClusterAnalysis

a = StudentFuzzy(2, 0.5, 5)
b = StudentFuzzy(3, 0.8, 5)
print(a + b, a * b, a < b, a.alpha_cut(0.5))

fs = generate_set(200, seed=1)
ca = ClusterAnalysis(fs)
labels = ca.labels_for_k(7)           # 7 кластеров
labels = ca.labels_for_threshold(5.0) # по критерию: порог расстояния
```
